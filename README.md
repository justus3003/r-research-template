# R Blueprint

Lightweight template for **analysis projects** in R.
Tooling: **rv** (packages), **air** (formatter), **jarl** (linter), **Quarto** (reports),
**prek/pre-commit** (Git hooks) and **GitHub Actions**.

## To-Do's

- [ ] Install the tools: R, `rv`, `air`, `jarl`, `quarto`, `prek` (or `pre-commit`), `make`
- [ ] Set the R version in `rproject.toml` (`r_version`) and `.github/actions/setup-r-env/action.yaml`
- [ ] Run `./setup.sh` (installs the packages with `rv sync` and the Git hooks)
- [ ] Commit `rv.lock` (generated by `rv sync`)
- [ ] Replace the example code in `R/` and `analysis/` with your own

## Structure

| Path | Purpose |
|---|---|
| `R/` | Your R code. `helpers.R` holds reusable functions, `01_prepare_data.R` is a numbered pipeline step |
| `analysis/` | Quarto documents (`report.qmd`) and their settings (`_quarto.yml`) |
| `data/` | Input and intermediate data (contents are gitignored) |
| `rproject.toml`, `rv.lock` | rv: package list and exact versions |
| `air.toml`, `jarl.toml` | Formatter and linter settings |
| `.pre-commit-config.yaml` | Git hooks (secret scan, air, jarl) |
| `Makefile` | Shortcuts for common commands |
| `.github/` | Automatic checks on GitHub |
| `.vscode/` | Optional settings for VS Code / Positron, delete if unused |

## Workflow

```bash
make sync     # install packages (rv sync)
make data     # run R/01_prepare_data.R
make render   # render the Quarto report to analysis/_output/
make run      # data + render
make format   # format code (air)
make lint     # check code (jarl)
make help     # list all tasks
```

Scripts are run from the project root, e.g. `Rscript R/01_prepare_data.R`. Paths inside code use `here::here()`,
so they work no matter where a script or document is started from.

## Adding packages

1. Add the package name to `dependencies` in `rproject.toml`
2. Run `make sync`
3. Commit `rproject.toml` and `rv.lock`

## Notes

- **rv activation:** `rv init` creates `rv/scripts/activate.R` and `rv/scripts/rvr.R` and adjusts `.Rprofile`. The bundled
  `.Rprofile` sources these scripts if they exist. On a fresh checkout `rv sync` is enough. If `rv init` refuses to run
  because `rproject.toml` already exists, see https://a2-ai.github.io/rv-docs/
- **CI:** The composite action `setup-r-env` installs rv via its install script and points `R_LIBS` at the rv library.
  The jarl installer URL in `.github/workflows/code-style.yaml` is derived from the release naming pattern. Check it against
  https://jarl.etiennebacher.com and pin versions as needed.
- **Tests:** Not included to keep this version small. If your functions grow, consider the [package version of this template](https://github.com/justus3003/r-project-template).
